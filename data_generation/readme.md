# Fake Data Generator – README

Dieses Skript erzeugt realistische Testdaten für eine PostgreSQL-Datenbank in zwei Skalierungen (**small** und **large**). Es dient zur Entwicklung, zum Testen und zur Performance-Analyse.

---

## Voraussetzungen

- Python 3
- PostgreSQL
- Python-Pakete:
  - `psycopg2`
  - `faker`

Installation:

```bash
pip install psycopg2 faker
